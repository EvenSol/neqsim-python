# NeqSim Python 3.18.1

NeqSim Python 3.18.1 is a Python-layer patch release for portable process
archive serialization. It continues to bundle the NeqSim Java 3.18.0 engine.

## Fixes

- Register an explicit XStream converter for `java.util.IdentityHashMap`, so
  recycle-bearing `ProcessSystem` objects save and reopen on Java 17 and newer
  without `--add-opens` JVM flags.
- Write `save_neqsim()` output transactionally beside the destination and
  atomically replace the destination only after the ZIP archive is complete.
  A failed save no longer leaves a partial archive at the requested path or
  replaces an existing valid archive.
- Add end-to-end Java 17 and Java 21 regression coverage for saving, reopening,
  checking named units, rerunning, and confirming a recycle process remains
  solved.

## Install

```bash
pip install --upgrade neqsim==3.18.1
```

Requirements remain Python 3.10 or newer and Java 17 or newer.
